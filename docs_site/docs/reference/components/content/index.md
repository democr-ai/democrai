# Content Components

[<- Back to Components Index](../index.md)

Content components render the information an end user reads, watches, or listens to inside a module page. They cover text surfaces (titles, paragraphs, Markdown), media (images, audio, video, PDF, QR codes), status indicators (badges, alerts, progress bars), and inline tags. Use them to populate a layout with informational or decorative content, distinct from interactive inputs and navigation.
